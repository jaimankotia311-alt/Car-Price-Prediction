🚗 **Car Price Prediction Using Machine Learning**

A machine learning project that predicts car prices based on various features, including engine size, horsepower, curb weight, fuel type, body style, and fuel efficiency. The project involves exploratory data analysis (EDA), data preprocessing, categorical encoding, and Linear Regression model training and evaluation using R² Score, MAE, MSE, and RMSE. The trained model is saved using Joblib and integrated into an interactive Streamlit web application for user-friendly car price predictions.
